# Privacy page deployment

The Play listing URL used by the app is planned as `https://mdimamhosen.me/still-arrows-privacy/`. Copy this directory to that path on the existing `mdimamhosen.me` site (or publish it with GitHub Pages and update the URL in the app's Settings screen and Play listing). Confirm the page is publicly reachable before submitting the listing. This workspace cannot publish to the domain without its hosting access.
